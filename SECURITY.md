# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest (main) | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, report it privately by emailing the maintainer via GitHub:

1. Go to [github.com/hansschenker](https://github.com/hansschenker)
2. Click **Contact** to send a private message

You can expect a response within 48 hours. If the vulnerability is confirmed, a fix will be released as soon as possible.
